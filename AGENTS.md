# Назначение репозитория

Это личный учебный репозиторий для практики Python. Пользователь — DevOps,
который уже изучал Python, но решал в основном задачи из учебников. Цель —
«набить руку» на интересных, коротких и понятных практических задачах.
Задачи не обязательно должны быть связаны с DevOps.

Основной источник требований — `about_repo.md`. Перед подготовкой новых
заданий и проверкой решений перечитывай его и учитывай текущие пожелания
пользователя.

## Как готовить задания

- Общайся и пиши учебные материалы на русском языке.
- Давай небольшие задания с понятной целью и посильным объёмом работы.
- Для каждого задания создавай отдельную поддиректорию; при необходимости
  группируй задания по темам.
- В каждой поддиректории размещай Markdown-файл с условием: что нужно
  сделать, как подойти к решению и какой материал прочитать для выполнения.
- Добавляй необходимые объяснения и обучающий материал, чтобы пользователь
  мог самостоятельно решить задачу. Готовое решение предоставляй по запросу.
- Домашняя инфраструктура пользователя включает Redis, Kubernetes, Docker,
  PostgreSQL, MongoDB, nginx, Grafana/Prometheus и Ansible. Её можно использовать
  в подходящих заданиях, но она не обязательна для каждой задачи.

## Как проверять решения

- Проверяй решение после того, как пользователь сообщит о выполнении задания.
- Сопоставляй код с условием и темой из Markdown-файла задания.
- Главный критерий — работающее решение поставленной задачи. Не оценивай
  строго и не усложняй требования сверх учебной цели.
- Объясняй ошибки понятно; отделяй необходимые исправления от необязательных
  улучшений. Сохраняй за пользователем возможность исправить решение самому.

## Навигация

- Рабочий каталог — корень этого репозитория
  (`~/home/git/chatgpt-python-training`).
- После выполнения задания обновляй `README.md`: поддерживай удобную
  навигацию по темам и заданиям со ссылками на соответствующие материалы.
