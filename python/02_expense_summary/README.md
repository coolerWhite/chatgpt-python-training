# Задание 2. Куда ушли деньги?

Ты записываешь небольшие расходы в текстовый файл. Напиши программу,
которая прочитает записи и покажет общую сумму и расходы по категориям.
Подсчёт словарём уже знаком по первому заданию — теперь значения нужно
складывать, а данные получать из файла.

**Темы:** чтение файлов, `split()`, `int()`, повторение строк и словарей.
**Ориентир по времени:** 25–35 минут. Python 3 без дополнительных библиотек.

## Исходные данные

Рядом находится файл `expenses.txt`. Каждая непустая строка содержит
категорию и сумму в целых рублях, разделённые точкой с запятой:

```text
Еда;250
 Транспорт ; 60
Книги;150

еда;350
ТРАНСПОРТ;60
```

Для этого задания считаем, что все непустые строки корректны: содержат
ровно одну точку с запятой, непустую категорию и целое неотрицательное число.
Обработку повреждённых записей и отсутствующего файла пока делать не нужно.

## Что сделать

Создай в этой директории `solution.py`. Программа должна:

1. Прочитать соседний файл `expenses.txt` в кодировке UTF-8.
2. Пропустить пустые строки и строки только из пробельных символов.
3. Разделить каждую оставшуюся строку на категорию и сумму.
4. Удалить пробелы по краям категории и привести её к нижнему регистру.
5. Преобразовать сумму в число и накопить расходы по категориям в словаре.
6. Вывести общие расходы и сумму по каждой категории.

Ожидаемый вывод для исходного файла:

```text
Всего потрачено: 870 руб.
еда: 600 руб.
транспорт: 120 руб.
книги: 150 руб.
```

Порядок категорий любой. Новые категории должны учитываться без изменения
кода. Для пустого файла выведи только `Всего потрачено: 0 руб.`.
Запись с нулевой суммой тоже учитывается: её категория должна попасть в вывод.

## Материал перед решением

### Чтение файла

`with` закрывает файл автоматически после завершения блока.
Перебор файла через `for` выдаёт его строки по одной:

```python
from pathlib import Path

path = Path(__file__).with_name("notes.txt")
with path.open(encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

`__file__` — путь к текущему скрипту, а `with_name()` заменяет имя файла
в этом пути. Так можно открыть файл рядом со скриптом независимо от того,
из какой директории его запустили. В своём решении используй имя `expenses.txt`.

Прочитанная строка обычно содержит символ перевода строки `\n` в конце.
Уже знакомый `strip()` убирает его вместе с пробелами по краям.

### Разделение строки

`split(";")` возвращает список частей строки, разделённых точкой с запятой:

```python
record = "карандаш;12"
parts = record.split(";")
print(parts)  # ['карандаш', '12']
```

Если частей ровно две, их можно сразу записать в две переменные:

```python
product, price_text = record.split(";")
```

Это называется распаковкой. Сначала пропускай пустые строки: у них нет двух частей.

### Из текста в число

После чтения файла сумма остаётся строкой. `int()` превращает текст
с целым числом в число, с которым можно выполнять арифметические операции:

```python
price_text = " 12 "
price = int(price_text.strip())
print(price + 3)  # 15
```

Помни разницу: `"12" + "3"` даёт `"123"`, а `12 + 3` даёт `15`.

### Накопление суммы

В первом задании ты увеличивал значение словаря на единицу за каждый голос.
Здесь нужно прибавлять сумму текущей записи. При первом появлении категории
создай для неё запись. Словарь создавай один раз, до цикла чтения файла.

Общий итог можно получить через `sum(имя_словаря.values())`, а для вывода
категорий использовать уже знакомые `items()` и f-строки.
