# Задание 1. Что заказываем на ужин?

Друзья голосуют за еду в чате. Кто-то пишет название большими буквами,
кто-то добавляет пробелы, а кто-то отправляет пустое сообщение.
Напиши программу, которая приведёт ответы к единому виду и посчитает голоса.

**Темы:** строки, списки, словари, цикл `for`, условия.
**Ориентир по времени:** 20–30 минут. Достаточно обычного Python 3 без дополнительных библиотек.

## Что сделать

Создай рядом с этим файлом `solution.py` и помести в него исходный список:

```python
votes = [
    "Пицца",
    " суши ",
    "ПИЦЦА",
    "бургер",
    "Суши",
    "",
    "  пицца  ",
    "   ",
    "БУРГЕР",
    "тако",
]
```

Программа должна:

1. Удалить пробелы по краям каждого ответа и привести буквы к нижнему регистру.
2. Пропустить ответы, которые после очистки стали пустыми.
3. Посчитать количество голосов за каждое блюдо с помощью словаря.
4. Напечатать количество учтённых голосов и результат для каждого блюда.

Пример результата для списка выше:

```text
Учтено голосов: 8
пицца: 3
суши: 2
бургер: 2
тако: 1
```

Порядок блюд в выводе любой. Названия блюд заранее неизвестны: если добавить
`"паста"`, программа должна учесть её без изменения логики.
Все элементы исходного списка — строки.

Если список пустой или содержит только пробельные строки, выведи
`Учтено голосов: 0`, без строк с блюдами.

## Материал перед решением

Прочитай этот раздел и попробуй маленькие примеры в интерпретаторе Python.
Они показывают инструменты, которые понадобятся в задании.

### Строки: очистка и регистр

`strip()` убирает пробельные символы по краям строки, а `lower()` переводит
буквы в нижний регистр. Методы возвращают новую строку; исходная не меняется.

```python
message = "  ПрИвЕт  "
cleaned = message.strip()
print(cleaned)          # ПрИвЕт
print(cleaned.lower())  # привет
```

Методы можно вызывать цепочкой: `message.strip().lower()`.
Пустую строку можно проверить через `text == ""` или `if not text`.

### Список и цикл

Цикл `for` позволяет по очереди обработать каждый элемент списка.
`continue` пропускает остаток текущей итерации и переходит к следующей.

```python
names = ["Аня", "", "Борис"]
for name in names:
    if not name:
        continue
    print(name)
```

### Словарь

Словарь хранит пары «ключ — значение». Например, имя товара и его остаток:

```python
stock = {"карандаш": 4}
stock["тетрадь"] = 2          # добавить новый ключ
stock["карандаш"] += 1       # изменить существующее значение
print(stock.get("ластик", 0))  # 0: такого ключа пока нет
```

Обращение `stock["ластик"]` к отсутствующему ключу вызовет `KeyError`.
Перед изменением значения можно проверить наличие ключа через
`if "ластик" in stock` или воспользоваться `get(ключ, значение_по_умолчанию)`.

Метод `items()` позволяет перебрать ключи вместе со значениями:

```python
for product, quantity in stock.items():
    print(f"{product}: {quantity}")
```

В строке с префиксом `f` выражения внутри фигурных скобок заменяются их
значениями. Так удобно собирать итоговый вывод.

## Как подойти к решению

Сначала добейся вывода очищенных непустых ответов. Затем добавь словарь
для подсчёта. В конце выведи результаты. Общее количество голосов можно
считать отдельной переменной или получить через `sum(counts.values())`,
если твой словарь называется `counts`.
