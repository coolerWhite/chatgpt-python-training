# Задание 3. Расходы с опечатками

Во втором задании все записи были корректными. Теперь в файле встречаются
ошибки: пропущенная сумма, лишний разделитель или текст вместо числа.
Сделай так, чтобы программа пропускала такие записи и продолжала работу.

**Темы:** функции, `return`, `None`, `try/except`, проверка данных.
**Ориентир по времени:** 30–40 минут. Python 3 без дополнительных библиотек.

## Что сделать

Создай рядом `solution.py`. Можно взять своё решение второго задания за основу,
но исходное решение оставь в его директории. Здесь используй соседний
`expenses.txt`, который уже содержит примеры ошибок.

### 1. Функция разбора одной строки

Напиши функцию `parse_expense(line)`. Она принимает строку и возвращает:

- пару `(category, amount)`, если запись корректная;
- `None`, если строка пустая или запись некорректная.

Корректная запись содержит ровно две части, разделённые `;`:

- категория после `strip()` не пустая; приведи её к нижнему регистру;
- сумма после удаления пробелов преобразуется через `int()` и не меньше нуля.

Нулевые суммы допустимы. Дробные суммы, например `12.5`, пока не поддерживаются.
Если `int()` принимает запись (например, `+10`), считай её допустимой при
неотрицательном результате. Дополнительную проверку формата числа делать не нужно.

Функция только разбирает строку: не читает файл, не печатает результат и
не меняет общий словарь расходов.

### 2. Обработка файла

В основном цикле чтения файла:

1. Пропускай пустые и пробельные строки — они не считаются ошибками.
2. Передавай каждую непустую строку в `parse_expense()`.
3. Если вернулся `None`, увеличивай счётчик ошибочных записей.
4. Иначе распаковывай результат и прибавляй сумму к нужной категории.

В конце выведи общую сумму, суммы по категориям и число ошибочных записей.
Порядок категорий любой. Для исходного файла ожидается:

```text
Всего потрачено: 530 руб.
еда: 350 руб.
транспорт: 80 руб.
книги: 100 руб.
Ошибочных записей: 5
```

Обработку отсутствующего файла делать не нужно.

## Материал перед решением

### Функции и возвращаемое значение

Функция позволяет дать имя небольшому действию и выполнять его многократно.
Аргумент передаёт данные внутрь, а `return` возвращает результат и сразу
завершает вызов функции:

```python
def normalize_name(text):
    return text.strip().lower()

name = normalize_name("  АНЯ ")
print(name)  # аня
```

`print()` показывает значение на экране, а `return` передаёт его вызывающему
коду. Это разные действия.

### `None` и пара значений

`None` удобно использовать как сигнал «результата нет». Проверяй его через
`result is None`. Несколько значений можно вернуть кортежем:

```python
def get_position(known):
    if not known:
        return None
    return (3, 7)

position = get_position(True)
if position is not None:
    x, y = position
    print(x, y)
```

Распаковывай результат только после проверки: `None` нельзя разложить
на две переменные.

### Проверка числа частей

`split(";")` возвращает список. `len(parts)` показывает, сколько в нём
элементов. Перед распаковкой убедись, что их ровно два — это поможет избежать
знакомой ошибки `not enough values to unpack` и ошибки из-за лишних частей.

### `try/except`

`int("сто")` вызывает `ValueError`. Эту конкретную ошибку можно перехватить:

```python
text = "много"
try:
    quantity = int(text)
except ValueError:
    print("Ожидалось целое число")
```

В твоей функции при такой ошибке нужно вернуть `None`. Помести в `try`
только преобразование числа. Отрицательное число успешно преобразуется
через `int()`, поэтому его нужно проверить отдельным условием.

Сначала напиши функцию и проверь её несколькими отдельными вызовами.
Затем подключи её к чтению файла и подсчёту расходов.

| Аргумент `parse_expense()` | Ожидаемый результат |
| --- | --- |
| `" КОФЕ ; 120\n"` | `("кофе", 120)` |

| `"кофе;-50"` или `"кофе;12.5"` | `None` |

- Одна строка `сломано`: общая сумма 0, ошибок 1, без категорий.
- Одна строка `игры;0`: общая сумма 0, категория игры — 0, ошибок 0.
